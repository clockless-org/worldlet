# Cookie Clicker

Bake cookies, buy grandmas and factories, bake even more cookies.

A popular web game in the Games area shelf (owner request 2026-10-03: import the most popular games from Sekai and similar game communities when they already have a playable link). Why it is here: The classic idle game, online since 2013. It is a website Applet: it opens `https://orteil.dashnet.org/cookieclicker/` (DashNet), free to play without an account, and reads nothing. The device art is the game's own art on the shared arcade frame ([provenance](../../../resources/styles/builtin/assets/applets/web-games-provenance.json)).

## Runtime
