# Slither.io

Grow the longest snake in a live arena full of other players.

A popular web game in the Games area shelf (owner request 2026-10-03: import the most popular games from Sekai and similar game communities when they already have a playable link). Why it is here: One of the highest-traffic browser games for about a decade. It is a website Applet: it opens `https://slither.io/` (slither.io), free to play without an account, and reads nothing. The device art is the game's own art on the shared arcade frame ([provenance](../../../resources/styles/builtin/assets/applets/web-games-provenance.json)).
