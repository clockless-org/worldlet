# Rive Fox

Generated by [`scripts/fox-rive/build.py`](../../../../../../scripts/fox-rive/build.py); do not edit by hand.

- `states.json`: performance name to the `state` number the `Fox` state machine reads.
- `fox.riv`: the compiled runtime file the portrait plays.

The build also writes `fox.rml` (the Rive source, which the Rive editor or MCP can open), `rive.yaml` and `textures/` here. They are intermediate output, regenerated on every build, and not committed.

Rebuild after changing the rig or a performance:

```sh
curl -fsSL https://releases.rive.app/cli/install.sh | bash   # once; Linux also needs libegl1 libgles2
python3 -m pip install numpy scipy pillow                    # once
python3 scripts/fox-rive/build.py
node scripts/fox-rive-check.ts
```

How the rig, the performances and the runtime fit together: [Fox animation](../../../../../../ui/companion/ANIMATION.md#rive-fox).
