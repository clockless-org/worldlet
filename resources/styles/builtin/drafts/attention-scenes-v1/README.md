# Attention scene library v1

100 reusable scene subjects for Attention cards, generated with the built-in ImageGen tool on 2026-09-26. The tool does not expose its model identifier or provide a price receipt.

## Composition

These are complete full-bleed landscape illustrations in Worldlet's `cozy-miniature@1.0.0` direction. All four corners contain scene content. No blank title area, feathered edges, baked vignette, UI, or captions. The user explicitly requested full images; card cropping and edge treatment are deferred to a shared presentation step.

The unmodified generated PNG outputs were removed from the checkout (recoverable in Git history); `images/` keeps only the few still read by code or tests. `catalog.json` records stable subject IDs, groups, exact prompts, source artifacts and generation status. `tennis-layout-study.png` is the earlier ivory-background study, superseded by the full-scene direction and excluded from the 100-image count.

These are illustrative generic scenes, not photographs or factual evidence of a user's event, venue or circumstances. Serious information scenes use calm practical subjects without implying a good outcome. The 100 scenes now ship as registered 768px WebP derivatives in `../../assets/attention/scenes/`, with keyword metadata in `../../assets/attention/scenes.json`. Original outputs and prompts stay here as provenance. The three category images remain fallbacks; the shared HUD mask supplies the edge feathering at runtime.

## Subjects

Ten groups of ten: sports, gatherings, work, travel, home, health, money, learning, culture and information.

Open `index.html` to browse subjects and click a preview to view its full original. Dimensions are recorded from the outputs; they are generator-selected, not a card-layout requirement. Final visual acceptance of the scene library remains with the user.
