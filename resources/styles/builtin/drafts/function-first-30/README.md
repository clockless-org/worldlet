# Function-first common 30

This is a curated common-app production batch, not a measured global popularity ranking. It includes YouTube as the retained approved benchmark and 29 regenerated devices listed in `concepts.json`.

## Acceptance

1. Recognizable physical function before branding: e.g. publishing desk, headphones/microphone, document organizer.
2. Brand identity through sculpture, shape, color and proportionate inlaid marks, never a giant flat app icon on a generic box. Recognizable icon or branded sculpture occupies approximately HALF the composition; functional parts occupy the rest.
3. Gentle 18–22° yaw and 25° downward view, painted miniature materials, clear top and side thickness.
4. Shared main-body visual scale and foot baseline. Alpha-weighted sizing is a starting point followed by small-scale visual review.

## Production

Official OpenAI Images Edit API, `gpt-image-2.5-sunburst`, high, native 1024×1024 with transparent background. Untouched master PNGs, exact prompts and sanitized request metadata are stored here. `normalization.json` records the uniformly scaled runtime derivatives at `assets/applets/<key>/peek.png`.

YouTube uses the approved `../gentle-angle/youtube.png` master and existing runtime sprite unchanged. Only Peek and Open that already shares Peek are replaced. Separate Focus paintings and original publisher icons used by identity UI remain separate assets.
