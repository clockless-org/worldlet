# Moment Applet device

Every [moment Applet](../../../../../core/artifacts/README.md)'s device is the painted screen stand of the dormant `things` Peek sprite, with its frame repainted a warm amber and its face redrawn as a small page for the moment: a map with a path and a pin over two ticked rows. No image model was used and no third-party artwork was added.

Run `python3 resources/styles/builtin/drafts/moment/compose.py` (Pillow and NumPy) to rewrite `assets/applets/moment/peek-logo-v3.png`. The output is deterministic.
