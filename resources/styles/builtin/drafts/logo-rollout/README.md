# Full Applet identity rollout

This extends the approved logo-first batch to the complete registered device library, including Mac application launcher artwork. The village, landmarks, five ground slots and user placements are unchanged.

## Production contract

- All 112 registered Peek devices use the updated `peek-logo-v3.png` family. The initial eight preserved devices have now also been refreshed.
- Use the repository's sourced publisher icon for brand identity. Decode ICO/SVG to a temporary PNG reference without redesigning it. Existing unbranded devices provide identity for the generic Home family, Weather, Meetings and Browser.
- Keep the original icon's shape dominant. Add at most two small functional cues. Use rounded matte painted surfaces, restrained timber/brass details and the fixed village camera.
- Original publisher icons remain separate from generated interpretations; authorization and identity UI still use sourced originals.
- No new account data, unread counts or animation claims are embedded in these images. Browser Focus scenery and authored Open content are separate assets, not regenerated by this device rollout.

Each JSON file records the exact prompt, input paths, generated master, output path and review state. Masters are preserved without recoloring. Contact sheets show Region-size artwork alongside 84px overview thumbnails. Runtime builds derive smaller WebP textures through the existing pipeline.

## Scope

The style registry includes artwork beyond the currently active service catalog. Existing Mac application resources such as Photos, Pages, Numbers, Keynote, Safari, Chrome, Firefox, VS Code and Cursor are included even when their launcher definition is not active. Producing their artwork does not silently add or reinstall an application or change its launch behavior.

## Acceptance

Before promotion: inspect every contact sheet, verify transparent alpha, check recognizable silhouette and secondary function, calibrate perceived size, validate all registry paths, build the native interface and confirm fixed-slot navigation remains intact. Final product acceptance happens on main.
