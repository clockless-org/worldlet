# Gentle-angle common Applets

Refines the twelve front-facing devices after visual feedback: 18–22° horizontal yaw, about 25° downward view, dominant recognizable front with visible top and right-side thickness. Brand identity shares the device material, perspective and lighting. No runtime image rotation or pasted logo overlay.

Generated through the official OpenAI Images Edit API using `gpt-image-2.5-sunburst`, high quality, 1024×1024 with transparent alpha. Exact prompts and sanitized request metadata accompany each untouched master. Runtime derivatives use the same alpha-weighted body-size calibration as the preceding batch; measurements are in `normalization.json`.

Scope: YouTube, X, Discord, Slack, Notion, Spotify, WeChat, WhatsApp, Telegram, GitHub, Linear and Cloudflare Peek sprites, plus Open where it shares Peek. Dedicated Focus scene paintings are unchanged.
